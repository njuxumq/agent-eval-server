# 链路追踪设计文档

## 一、概述

### 1.1 设计目标

实现端到端的请求追踪，覆盖：
- 用户请求从提交到完成的全生命周期
- 调度服务与执行服务间的调用链
- 沙箱操作和外部服务调用的追踪
- 支持问题定位、性能分析和依赖可视化

### 1.2 适用范围

| 服务 | 追踪范围 |
|------|----------|
| 调度服务 | API接口、任务管理、DAG调度、子任务分发 |
| 执行服务 | 子任务执行、沙箱管理、结果上报 |
| 外部调用 | AgentCube SDK、eval-data API、MongoDB操作 |

### 2.1 技术栈

| 组件 | 选择 | 说明 |
|------|------|------|
| **追踪标准** | OpenTelemetry | 业界标准，社区活跃 |

## 四、集成实现

### 4.1 初始化配置

```go
// internal/pkg/tracing/tracing.go
package tracing

import (
    "context"
    
    "go.opentelemetry.io/otel"
    "go.opentelemetry.io/otel/attribute"
    "go.opentelemetry.io/otel/exporters/otlp/otlptrace"
    "go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc"
    "go.opentelemetry.io/otel/propagation"
    "go.opentelemetry.io/otel/sdk/resource"
    "go.opentelemetry.io/otel/sdk/trace"
    semconv "go.opentelemetry.io/otel/semconv/v1.21.0"
    "go.uber.org/zap"
)

var (
    Tracer trace.Tracer
    logger *zap.Logger
)

type Config struct {
    ServiceName    string
    ServiceVersion string
    OTLPEndpoint   string
    SampleRate     float64  // 采样率 0.0-1.0
    Enabled        bool
}

// Init 初始化链路追踪
func Init(cfg *Config, log *zap.Logger) (func(context.Context) error, error) {
    logger = log
    
    if !cfg.Enabled {
        logger.Info("tracing disabled, using no-op tracer")
        Tracer = trace.NewNoopTracerProvider().Tracer("agent-eval-server")
        return func(ctx context.Context) error { return nil }, nil
    }
    
    // 1. 创建OTLP exporter
    exporter, err := otlptrace.New(
        context.Background(),
        otlptracegrpc.NewClient(
            otlptracegrpc.WithEndpoint(cfg.OTLPEndpoint),
            otlptracegrpc.WithInsecure(),
        ),
    )
    if err != nil {
        return nil, err
    }
    
    // 2. 创建资源
    res, err := resource.Merge(
        resource.Default(),
        resource.NewWithAttributes(
            semconv.SchemaURL,
            semconv.ServiceName(cfg.ServiceName),
            semconv.ServiceVersion(cfg.ServiceVersion),
        ),
    )
    if err != nil {
        return nil, err
    }
    
    // 3. 创建TracerProvider
    tp := trace.NewTracerProvider(
        trace.WithBatcher(exporter,
            trace.WithBatchTimeout(5*time.Second),
            trace.WithExportTimeout(30*time.Second),
        ),
        trace.WithResource(res),
        trace.WithSampler(newCustomSampler(cfg.SampleRate)),
    )
    
    // 4. 设置全局Tracer
    otel.SetTracerProvider(tp)
    otel.SetTextMapPropagator(propagation.NewCompositeTextMapPropagator(
        propagation.TraceContext{},
        propagation.Baggage{},
    ))
    
    // 5. 创建Tracer实例
    Tracer = tp.Tracer("github.com/example/agent-eval-server")
    
    logger.Info("tracing initialized",
        zap.String("service", cfg.ServiceName),
        zap.String("endpoint", cfg.OTLPEndpoint),
        zap.Float64("sample_rate", cfg.SampleRate),
    )
    
    // 6. 返回关闭函数
    return tp.Shutdown, nil
}

// StartSpan 启动一个新的span
func StartSpan(ctx context.Context, name string, opts ...trace.SpanStartOption) (context.Context, trace.Span) {
    return Tracer.Start(ctx, name, opts...)
}

// SpanFromContext 从context获取当前span
func SpanFromContext(ctx context.Context) trace.Span {
    return trace.SpanFromContext(ctx)
}
```

### 4.2 自定义采样器

```go
// internal/pkg/tracing/sampler.go
package tracing

import (
    "strings"
    
    "go.opentelemetry.io/otel/sdk/trace"
)

// CustomSampler 自定义采样器
type CustomSampler struct {
    alwaysSamplePatterns []string
    sampleRate           float64
    baseSampler          trace.Sampler
}

func newCustomSampler(sampleRate float64) *CustomSampler {
    return &CustomSampler{
        alwaysSamplePatterns: []string{
            // 关键操作始终采样
            "CreateTask",
            "ExecuteSubTask",
            "ExtendDAG",
            "ReportStatus",
            "CreateSandbox",
            "ExecuteCommand",
            // 错误操作
            "error",
            "failed",
        },
        sampleRate:    sampleRate,
        baseSampler:   trace.TraceIDRatioBased(sampleRate),
    }
}

func (s *CustomSampler) ShouldSample(p trace.SamplingParameters) trace.SamplingResult {
    // 关键操作始终采样
    for _, pattern := range s.alwaysSamplePatterns {
        if strings.Contains(p.Name, pattern) {
            return trace.SamplingResult{
                Decision: trace.RecordAndSample,
            }
        }
    }
    
    // 其他操作按比例采样
    return s.baseSampler.ShouldSample(p)
}

func (s *CustomSampler) Description() string {
    return "CustomSampler"
}
```

### 4.3 API层中间件

```go
// internal/scheduler/api/middleware/tracing.go
package middleware

import (
    "github.com/gin-gonic/gin"
    "go.opentelemetry.io/otel"
    "go.opentelemetry.io/otel/attribute"
    "go.opentelemetry.io/otel/codes"
    "go.opentelemetry.io/otel/propagation"
    "go.opentelemetry.io/otel/trace"
    
    "github.com/example/agent-eval-server/internal/pkg/tracing"
)

// TracingMiddleware 链路追踪中间件
func TracingMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 1. 从请求头提取trace context
        ctx := otel.GetTextMapPropagator().Extract(
            c.Request.Context(),
            propagation.HeaderCarrier(c.Request.Header),
        )
        
        // 2. 创建span名称
        spanName := c.Request.Method + " " + c.FullPath()
        if spanName == "" {
            spanName = c.Request.Method + " " + c.Request.URL.Path
        }
        
        // 3. 创建span
        ctx, span := tracing.Tracer.Start(ctx, spanName,
            trace.WithSpanKind(trace.SpanKindServer),
            trace.WithAttributes(
                attribute.String(tracing.AttributeHTTPMethod, c.Request.Method),
                attribute.String(tracing.AttributeHTTPURL, c.Request.URL.String()),
                attribute.String(tracing.AttributeHTTPRoute, c.FullPath()),
                attribute.String(tracing.AttributeHTTPRequestSize, 
                    strconv.Itoa(c.Request.ContentLength)),
            ),
        )
        defer span.End()
        
        // 4. 将context放入gin context
        c.Request = c.Request.WithContext(ctx)
        
        // 5. 执行请求
        c.Next()
        
        // 6. 记录响应状态
        span.SetAttributes(
            attribute.Int(tracing.AttributeHTTPStatusCode, c.Writer.Status()),
        )
        
        // 7. 记录错误
        if len(c.Errors) > 0 {
            span.SetStatus(codes.Error, c.Errors.String())
            span.RecordError(c.Errors.Last())
        } else if c.Writer.Status() >= 400 {
            span.SetStatus(codes.Error, "HTTP "+strconv.Itoa(c.Writer.Status()))
        } else {
            span.SetStatus(codes.Ok, "")
        }
    }
}
```

// internal/executor/client/scheduler_client.go
package client

import (
    "net/http"
    
    "go.opentelemetry.io/otel"
    "go.opentelemetry.io/otel/attribute"
    "go.opentelemetry.io/otel/codes"
    "go.opentelemetry.io/otel/propagation"
    "go.opentelemetry.io/otel/trace"
    
    "github.com/example/agent-eval-server/internal/pkg/tracing"
)

// ReportSubTaskStatus 上报子任务状态
func (c *SchedulerClient) ReportSubTaskStatus(ctx context.Context, req *StatusReportRequest) error {
    // 创建span
    ctx, span := tracing.Tracer.Start(ctx, "SchedulerClient.ReportSubTaskStatus",
        trace.WithSpanKind(trace.SpanKindClient),
        trace.WithAttributes(
            attribute.String(tracing.AttributeSubTaskId, req.SubTaskId),
            attribute.String(tracing.AttributeTaskId, req.TaskId),
            attribute.String(tracing.AttributeStatus, req.Status),
            attribute.String(tracing.AttributeExternalService, "scheduler"),
            attribute.String(tracing.AttributeExternalMethod, "POST /internal/subtasks/status"),
        ),
    )
    defer span.End()
    
    // 创建HTTP请求
    body, _ := json.Marshal(req)
    httpReq, err := http.NewRequestWithContext(ctx, "POST", 
        c.baseURL+"/internal/subtasks/status", bytes.NewReader(body))
    if err != nil {
        span.RecordError(err)
        span.SetStatus(codes.Error, err.Error())
        return err
    }
    
    // 设置请求头
    httpReq.Header.Set("Content-Type", "application/json")
    
    // 注入trace context到请求头
    otel.GetTextMapPropagator().Inject(ctx, propagation.HeaderCarrier(httpReq.Header))
    
    // 发送请求
    startTime := time.Now()
    resp, err := c.httpClient.Do(httpReq)
    duration := time.Since(startTime)
    
    if err != nil {
        span.RecordError(err)
        span.SetStatus(codes.Error, err.Error())
        return err
    }
    defer resp.Body.Close()
    
    // 记录响应
    span.SetAttributes(
        attribute.Int(tracing.AttributeHTTPStatusCode, resp.StatusCode),
        attribute.Int64(tracing.AttributeExternalStatus, int64(resp.StatusCode)),
        attribute.Int64("http.duration_ms", duration.Milliseconds()),
    )
    
    if resp.StatusCode >= 400 {
        span.SetStatus(codes.Error, "HTTP "+strconv.Itoa(resp.StatusCode))
    } else {
        span.SetStatus(codes.Ok, "")
    }
    
    return nil
}

### 5.1 Span清单

| 操作 | Span名称 | Span类型 | 关键属性 |
|------|----------|----------|----------|
| 任务提交 | `POST /v1/tasks` | Server | app_id, workflow |

| DAG扩展 | `DAGExtender.ExtendDAG` | Internal | task_id, case_count |
| DAG节点释放 | `DAGScheduler.ReleaseNode` | Internal | node_id, task_id |
| 子任务分发 | `Dispatcher.Dispatch` | Internal | subtask_id, executor |
| 子任务执行 | `SubTaskManager.ExecuteSubTask` | Internal | subtask_id, stage |
| 沙箱创建 | `SandboxManager.CreateSandbox` | Internal | subtask_id, sandbox_id |

# monitoring/prometheus/rules/tracing_rules.yml
groups:
  - name: tracing.rules
    rules:
      # P99延迟告警
      - alert: HighP99Latency
        expr: histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[5m])) > 0.5
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High P99 latency detected"
          description: "P99 latency is {{ $value }}s for {{ $labels.service_name }}"
      
      # 错误率告警
      - alert: HighErrorRate
        expr: sum(rate(span_errors_total[5m])) by (service_name) / sum(rate(spans_total[5m])) by (service_name) > 0.01
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High error rate detected"
          description: "Error rate is {{ $value }} for {{ $labels.service_name }}"
      
      # 外部服务调用延迟告警
      - alert: SlowExternalCalls
        expr: histogram_quantile(0.95, rate(span_duration_seconds_bucket{span_kind="client"}[5m])) > 1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Slow external service calls"
          description: "P95 external call latency is {{ $value }}s"

## 九、最佳实践

### 9.1 Span命名规范

| 场景 | 格式 | 示例 |
|------|------|------|
| HTTP接口 | `{METHOD} {path}` | `POST /v1/tasks` |
| 业务操作 | `{Component}.{Method}` | `TaskManager.CreateTask` |
| 数据库操作 | `{DB} {operation}` | `MongoDB.Insert` |
| 外部调用 | `{Client}.{Method}` | `SchedulerClient.ReportStatus` |

### 9.2 属性命名规范

- 使用 `.` 分隔命名空间
- 使用snake_case格式
- 业务属性使用 `eval.` 前缀
- 自定义属性使用项目前缀

### 9.3 采样策略建议

| 环境 | 采样率 | 说明 |
|------|--------|------|
| 开发环境 | 100% | 便于调试 |
| 测试环境 | 50% | 平衡性能和可观测性 |
| 生产环境 | 10% | 降低存储成本 |

### 9.4 性能优化

1. **批量导出**：使用BatchSpanProcessor而非SimpleSpanProcessor
2. **异步导出**：设置合理的BatchTimeout和ExportTimeout
3. **属性限制**：每个Span属性数量不超过128个
4. **事件限制**：每个Span事件数量不超过128个
