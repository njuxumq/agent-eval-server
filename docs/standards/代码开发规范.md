# 代码开发规范文档

## 一、概述

### 1.1 文档目的

本文档定义应用评测服务（agent-eval-server）的代码开发规范，确保：
- 代码风格一致性，便于阅读和维护
- 项目结构规范化，便于团队协作
- 错误处理标准化，便于问题排查
- 日志输出规范化，便于监控告警
- 测试覆盖充分，保障代码质量

### 1.2 适用范围

| 适用项 | 说明 |
|--------|------|
| **语言** | Go 1.21+ |
| **服务** | 调度服务、执行服务 |
| **开发者** | 所有参与项目开发的成员 |

### 1.3 规范等级

| 等级 | 标识 | 说明 |
|------|------|------|
| **强制** | `[MUST]` | 必须遵守，违规将导致代码审查拒绝 |
| **推荐** | `[SHOULD]` | 建议遵守，特殊情况可例外 |
| **可选** | `[MAY]` | 可选遵守，不做强制要求 |

### 2.2 命名规范 `[MUST]`

#### 包命名

| 规则 | 示例 |
|------|------|
| 使用简短、有意义的小写单词 | `scheduler`, `executor`, `storage` |
| 不使用下划线或驼峰 | ❌ `task_manager`, ❌ `taskManager` |
| 不使用通用名称 | ❌ `util`, `common`, `lib` |

#### 文件命名

| 规则 | 示例 |
|------|------|
| 使用小写单词，下划线分隔 | `task_manager.go`, `dag_scheduler.go` |
| 测试文件以 `_test.go` 结尾 | `task_manager_test.go` |
| 接口实现文件可使用 `_impl.go` | `storage_impl.go` |

#### 变量命名

| 类型 | 规则 | 示例 |
|------|------|------|
| **局部变量** | 驼峰命名，简短有意义 | `taskId`, `node`, `err` |
| **常量** | 驼峰命名，导出常量首字母大写 | `MaxRetryCount`, `defaultTimeout` |
| **函数参数** | 驼峰命名，有意义 | `func CreateTask(ctx context.Context, taskId string)` |
| **结构体字段** | 驼峰命名，导出字段首字母大写 | `TaskId`, `Status`, `CreatedAt` |

#### 函数命名

| 类型 | 规则 | 示例 |
|------|------|------|
| **导出函数** | 驼峰命名，首字母大写 | `CreateTask()`, `GetSubTask()` |
| **内部函数** | 驼峰命名，首字母小写 | `parseConfig()`, `validateParams()` |
| **接口方法** | 动词+名词组合 | `Get()`, `Create()`, `Update()`, `Delete()` |
| **回调函数** | `On` + 事件名 | `OnTaskComplete()`, `OnNodeRelease()` |

#### 接口命名

| 规则 | 示例 |
|------|------|
| 单方法接口：动词+er | `Reader`, `Writer`, `Executor` |
| 多方法接口：名词 | `TaskManager`, `Storage` |

**示例**：

```go
// 单方法接口
type Executor interface {
    Execute(ctx context.Context, task *Task) error
}

// 多方法接口
type TaskStorage interface {
    Create(ctx context.Context, task *Task) error
    Get(ctx context.Context, taskId string) (*Task, error)
    Update(ctx context.Context, task *Task) error
    Delete(ctx context.Context, taskId string) error
}
```

```go
package errors

import "fmt"

// AppError represents a structured application error.
type AppError struct {
    Code    ErrorCode
    Message string
    Detail  string
}

func (e *AppError) Error() string {
    if e.Detail != "" {
        return fmt.Sprintf("%s: %s", e.Message, e.Detail)
    }
    return e.Message
}

// New creates a new AppError with the given code and message.
func New(code ErrorCode, message string) *AppError {
    return &AppError{
        Code:    code,
        Message: message,
    }
}

// Wrap wraps an error with additional detail.
func Wrap(err error, detail string) *AppError {
    if appErr, ok := err.(*AppError); ok {
        return &AppError{
            Code:    appErr.Code,
            Message: appErr.Message,
            Detail:  detail,
        }
    }
    return &AppError{
        Code:    ErrUnknown,
        Message: err.Error(),
        Detail:  detail,
    }
}

// Predefined errors
var (
    ErrTaskNotFound          = New(ErrTaskNotFoundCode, "task not found")
    ErrSubTaskNotFound       = New(ErrSubTaskNotFoundCode, "subtask not found")
    ErrNoAvailableExecutor   = New(ErrNoAvailableExecutorCode, "no available executor")
    ErrSandboxCreate         = New(ErrSandboxCreateCode, "sandbox create error")
    ErrSandboxExecuteTimeout = New(ErrSandboxTimeoutCode, "sandbox timeout error")
)
```

#### API层错误处理

```go
func (api *TaskAPI) HandleCreateTask(c *gin.Context) {
    var req TaskCreateRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        api.respondError(c, errors.ErrRequestBodyDecode, err.Error())
        return
    }

    taskId, err := api.manager.CreateTask(c.Request.Context(), &req)
    if err != nil {
        if appErr, ok := err.(*errors.AppError); ok {
            api.respondError(c, appErr.Code, appErr.Error())
        } else {
            api.respondError(c, errors.ErrUnknown, err.Error())
        }
        return
    }

    api.respondSuccess(c, gin.H{"task_id": taskId})
}

func (api *TaskAPI) respondError(c *gin.Context, code errors.ErrorCode, message string) {
    c.JSON(http.StatusOK, gin.H{
        "code":    code,
        "message": message,
        "data":    nil,
    })
}
```

## 五、日志规范

### 5.1 日志工具配置 `[MUST]`

**使用 zap 结构化日志**：

```go
package logger

import (
    "go.uber.org/zap"
    "go.uber.org/zap/zapcore"
)

var Log *zap.Logger

func Init(config *Config) error {
    var level zapcore.Level
    switch config.Level {
    case "debug":
        level = zapcore.DebugLevel
    case "info":
        level = zapcore.InfoLevel
    case "warn":
        level = zapcore.WarnLevel
    case "error":
        level = zapcore.ErrorLevel
    default:
        level = zapcore.InfoLevel
    }

    encoderConfig := zapcore.EncoderConfig{
        TimeKey:        "timestamp",
        LevelKey:       "level",
        NameKey:        "logger",
        CallerKey:      "caller",
        MessageKey:     "message",
        StacktraceKey:  "stacktrace",
        LineEnding:     zapcore.DefaultLineEnding,
        EncodeLevel:    zapcore.LowercaseLevelEncoder,
        EncodeTime:     zapcore.ISO8601TimeEncoder,
        EncodeDuration: zapcore.SecondsDurationEncoder,
        EncodeCaller:   zapcore.ShortCallerEncoder,
    }

    if config.Format == "json" {
        Log = zap.New(zapcore.NewCore(
            zapcore.NewJSONEncoder(encoderConfig),
            zapcore.AddSync(os.Stdout),
            level,
        ))
    } else {
        Log = zap.New(zapcore.NewCore(
            zapcore.NewConsoleEncoder(encoderConfig),
            zapcore.AddSync(os.Stdout),
            level,
        ))
    }

    return nil
}
```

### 5.2 日志级别使用 `[MUST]`

| 级别 | 使用场景 | 示例 |
|------|----------|------|
| **DEBUG** | 详细调试信息（开发环境） | 请求参数详情、中间状态 |
| **INFO** | 关键业务事件 | 任务创建、状态变更、流程里程碑 |
| **WARN** | 异常但可恢复的情况 | 重试触发、降级处理、配置缺失 |
| **ERROR** | 错误需要关注 | 执行失败、服务失联、数据错误 |
| **FATAL** | 系统不可恢复错误 | 启动失败、配置错误（服务退出） |

### 6.4 测试代码结构 `[SHOULD]`

```go
func TestCreateTask(t *testing.T) {
    // 1. 准备测试数据
    req := &TaskCreateRequest{
        AppId: "test-app",
        Config: &TaskConfig{
            Workflow: []string{"synthesis", "inference"},
        },
    }

    // 2. 准备mock对象
    mockStorage := &MockTaskStorage{}
    manager := NewTaskManager(mockStorage)

    // 3. 执行测试
    taskId, err := manager.CreateTask(context.Background(), req)

    // 4. 验证结果
    if err != nil {
        t.Errorf("CreateTask failed: %v", err)
    }
    if taskId == "" {
        t.Error("taskId should not be empty")
    }

    // 5. 验证mock调用
    if mockStorage.CreateCalledCount != 1 {
        t.Errorf("Storage.Create should be called once, got %d", mockStorage.CreateCalledCount)
    }
}
```

### 6.5 Mock使用规范 `[SHOULD]`

**接口定义便于mock**：

```go
// 定义接口而不是具体类型
type TaskStorage interface {
    Create(ctx context.Context, task *Task) error
    Get(ctx context.Context, taskId string) (*Task, error)
    Update(ctx context.Context, task *Task) error
}

// 业务逻辑使用接口
type TaskManager struct {
    storage TaskStorage
}

// Mock实现
type MockTaskStorage struct {
    CreateCalledCount int
    CreateErr         error
}

func (m *MockTaskStorage) Create(ctx context.Context, task *Task) error {
    m.CreateCalledCount++
    return m.CreateErr
}
```

### 6.6 表驱动测试 `[SHOULD]`

```go
func TestValidateRequest(t *testing.T) {
    tests := []struct {
        name    string
        req     *TaskCreateRequest
        wantErr bool
        errMsg  string
    }{
        {
            name: "valid request",
            req:  &TaskCreateRequest{AppId: "test-app", Config: validConfig()},
            wantErr: false,
        },
        {
            name: "empty app_id",
            req:  &TaskCreateRequest{AppId: "", Config: validConfig()},
            wantErr: true,
            errMsg: "app_id is required",
        },
        {
            name: "empty workflow",
            req:  &TaskCreateRequest{AppId: "test-app", Config: &TaskConfig{Workflow: []string{}}},
            wantErr: true,
            errMsg: "workflow must contain at least one stage",
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            err := ValidateRequest(tt.req)
            if tt.wantErr {
                if err == nil {
                    t.Errorf("ValidateRequest() should return error, got nil")
                }
                if err.Error() != tt.errMsg {
                    t.Errorf("ValidateRequest() error = %v, want %v", err.Error(), tt.errMsg)
                }
            } else {
                if err != nil {
                    t.Errorf("ValidateRequest() should not return error, got %v", err)
                }
            }
        })
    }
}
```
