# 数据管理服务接口文档

> 来源: `/home/xmq/projects/go/eval-data`

## 概述

数据管理服务 (eval-data) 提供:
- 评测集 (Evalset) 的存储与查询
- 评测记录 (Record) 的存储与查询

基础信息:
- 协议: HTTP
- 数据格式: JSON
- 响应格式: `{code, message, data}`

## 评测集接口 (Evalset)

### 上传评测集

**请求方法与路径**: `POST /v1/evalset/upload`

**请求参数**:

```json
{
    "schema_version": "1.0",
    "app_id": "maas",
    "evalset_id": "evalset-001",
    "items": [
        {
            "case_id": "case-001",
            "seq_id": 1,
            "model": "gpt-4",
            "system": "你是一个AI助手",
            "history": "",
            "question": "什么是机器学习?",
            "answer": "机器学习是...",
            "content": "",
            "category": "基础知识",
            "reference": "参考回答内容",
            "extends": {},
            "meta_info": {}
        }
    ]
}
```

**请求参数说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| schema_version | string | 否 | 版本号 |
| app_id | string | 是 | 应用ID |
| evalset_id | string | 是 | 评测集ID |
| items | array | 是 | 评测集条目列表(最大500条) |

**Item字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| case_id | string | 是 | 用例ID |
| seq_id | int | 是 | 序列ID(>=0) |
| model | string | 是 | 被评测模型名称 |
| system | string | 否 | 系统提示词 |
| history | string | 否 | 历史对话记录 |
| question | string | 是 | 问题 |
| answer | string | 是 | 模型回答 |
| content | string | 否 | 问题内容 |
| category | string | 否 | 问题分类 |
| reference | string | 否 | 参考回答 |
| extends | map | 否 | 扩展字段 |
| meta_info | map | 否 | 元信息 |

**响应示例**:

```json
{
    "code": 0,
    "message": "ok",
    "data": null
}
```

### 更新评测集

**请求方法与路径**: `POST /v1/evalset/upsert`

请求格式同上传接口，用于插入或更新已存在的评测集条目。

### 下载评测集

**请求方法与路径**: `GET /v1/evalset/download`

**请求参数** (URL参数):

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_id | string | 是 | 应用ID |
| evalset_id | string | 是 | 评测集ID |
| offset | int | 否 | 偏移量(默认0) |
| limit | int | 否 | 返回条数限制(默认无限制) |

**响应示例**:

```json
{
    "code": 0,
    "message": "ok",
    "data": [
        {
            "app_id": "maas",
            "evalset_id": "evalset-001",
            "case_id": "case-001",
            "seq_id": 1,
            "model": "gpt-4",
            "question": "什么是机器学习?",
            "answer": "机器学习是...",
            "created_at": 1761983527,
            "updated_at": 1761983627
        }
    ]
}
```

## 数据模型

### Evalset (评测集)

```go
type Evalset struct {
    AppId     string                 // 应用ID
    EvalsetId string                 // 评测集ID
    CaseId    string                 // 用例ID
    SeqId     int                    // 序列ID
    Model     string                 // 被评测模型名称
    System    string                 // 系统提示词
    History   string                 // 历史对话记录
    Question  string                 // 问题
    Answer    string                 // 模型回答
    Content   string                 // 问题内容
    Category  string                 // 问题分类
    Reference string                 // 参考回答
    Extends   map[string]string      // 扩展字段
    MetaInfo  map[string]interface{} // 元信息
    CreatedAt int64                  // 创建时间
    UpdatedAt int64                  // 更新时间
    ExpiredAt *time.Time             // 过期时间
}
```

**唯一性约束**: (app_id, evalset_id, case_id, seq_id, model)

### Record (评测记录)

```go
type Record struct {
    AppId     string                 // 应用ID
    TaskId    string                 // 任务ID
    EvalsetId string                 // 评测集ID
    SeqId     int                    // 序列ID
    CaseId    string                 // 用例ID
    Model     string                 // 被评测模型
    Name      string                 // 评测维度名称
    Category  string                 // 问题分类
    Type      string                 // 评测类型
    Func      string                 // 评测函数
    Result    interface{}            // 评测结果
    DType     string                 // 结果类型
    Reason    string                 // 评测理由
    MetaData  map[string]interface{} // 元数据
    Code      int                    // 评测状态码
    Message   string                 // 评测状态消息
    Thinking  string                 // 思考过程
    Content   string                 // 评测内容
    Hash      string                 // 评测内容哈希值
    Usage     map[string]interface{} // 资源使用
    CreatedAt int64                  // 创建时间
    UpdatedAt int64                  // 更新时间
    ExpiredAt *time.Time             // 过期时间
}
```

**唯一性约束**: (app_id, task_id, name, seq_id)

## 使用场景

### 应用评测服务集成

在应用评测服务的执行流程中:

1. **synthesis阶段** → 上传评测集到 `eval-data`
2. **inference阶段** → 从 `eval-data` 下载评测集
3. **eval阶段** → 上传评测记录到 `eval-data`
4. **report阶段** → 从 `eval-data` 下载评测记录

### 数据持久化示例

```go
// 上传评测集
evalsetItems := []*models.Evalset{...}
req := UploadEvalsetReq{
    AppId:     "maas",
    EvalsetId: "eval-001",
    Items:     evalsetItems,
}
postJSON("/v1/evalset/upload", req)

// 下载评测集
items := getJSON("/v1/evalset/download?app_id=maas&evalset_id=eval-001")

// 上传评测记录
recordItems := []*models.Record{...}
req := UploadRecordReq{
    AppId:  "maas",
    TaskId: "task-001",
    Items:  recordItems,
}
postJSON("/v1/record/upload", req)
```
