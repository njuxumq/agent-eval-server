# 评测工具交互说明

## 一、概述

### 1.1 文档目的

本文档定义评测工具（astron-eval）与执行服务的集成规范，包括：
- 命令行接口定义
- 输入/输出文件格式
- 执行环境要求
- 错误处理规范
- 与执行服务的集成方式

### 1.2 评测工具定位

评测工具（astron-eval）是运行在沙箱环境中的命令行工具，负责：
- **synthesis 阶段**：根据 Skill 生成评测用例（case）
- **inference 阶段**：驱动 Claude Code/Open Claw 加载 Skill 执行推理
- **eval 阶段**：根据交互记录计算评测指标
- **report 阶段**：汇总评测结果生成报告

### 1.3 工具架构

```

│                    沙箱环境 (AgentCube)                   │
│  ┌─────────────────────────────────────────────────┐    │

│  │                                                  │    │

│  │       │            │           │           │     │    │
```

## 二、命令行接口定义

### 2.1 通用参数

所有命令支持的通用参数：

| 参数 | 短参数 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| `--task-id` | `-t` | string | 是 | 任务 ID |
| `--config` | `-c` | string | 否 | 配置文件路径（默认 `/root/workspace/task.yaml`） |
| `--work-dir` | `-w` | string | 否 | 工作目录（默认 `/root/workspace`） |
| `--verbose` | `-v` | flag | 否 | 详细输出模式 |
| `--help` | `-h` | flag | 否 | 显示帮助信息 |

### 2.2 synthesis 命令

#### 命令格式

```bash
astron-eval synthesis --task-id <task_id> [options]
```

#### 专用参数

| 参数 | 短参数 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| `--count` | `-n` | int | 否 | 生成 case 数量（默认 10） |
| `--output` | `-o` | string | 否 | 输出目录（默认工作目录） |
| `--model` | `-m` | string | 否 | 用于生成的模型 ID |

#### 输入文件

| 文件 | 路径 | 说明 |
|------|------|------|
| Skills | `/root/workspace/skills/` | Skill 配置文件目录 |
| 配置文件 | `/root/workspace/task.yaml` | 任务配置文件 |

#### 输出文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 评测集 | `/root/workspace/evalset.jsonl` | 生成的评测集 |
| 数据集 | `/root/workspace/dataset.jsonl` | 原始数据集（可选） |

#### 执行示例

```bash
astron-eval synthesis \
  --task-id agent-eval-abc123 \
  --count 10 \
  --model ID_JUDGE_001 \
  --verbose
```

### 2.3 inference 命令

#### 命令格式

```bash
astron-eval inference --task-id <task_id> --case-id <case_id> [options]
```

#### 专用参数

| 参数 | 短参数 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| `--case-id` | | string | 是 | Case ID |
| `--evalset` | `-e` | string | 否 | 评测集文件路径（默认工作目录下的 evalset.jsonl） |
| `--timeout` | | duration | 否 | 执行超时时间（默认 10m） |
| `--agent-type` | `-a` | string | 否 | Agent 类型：claude-code/open-claw（默认 claude-code） |

#### 输入文件

| 文件 | 路径 | 说明 |
|------|------|------|
| Skills | `/root/workspace/skills/` | Skill 配置文件目录 |
| 评测集 | `/root/workspace/evalset.jsonl` | 评测集文件 |
| 配置文件 | `/root/workspace/task.yaml` | 任务配置文件 |

#### 输出文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 交互记录 | `/root/workspace/transcript.jsonl` | Agent 交互记录 |
| 更新的评测集 | `/root/workspace/evalset.jsonl` | 包含 answer 的评测集 |

#### 执行示例

```bash
astron-eval inference \
  --task-id agent-eval-abc123 \
  --case-id case-001 \
  --evalset /root/workspace/evalset.jsonl \
  --agent-type claude-code \
  --timeout 15m \
  --verbose
```

### 2.4 eval 命令

#### 命令格式

```bash
astron-eval eval --task-id <task_id> --case-id <case_id> [options]
```

#### 专用参数

| 参数 | 短参数 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| `--case-id` | | string | 是 | Case ID |
| `--transcript` | | string | 否 | 交互记录文件路径 |
| `--evalset` | `-e` | string | 否 | 评测集文件路径 |
| `--model` | `-m` | string | 否 | 评测模型 ID |

#### 输入文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 交互记录 | `/root/workspace/transcript.jsonl` | Agent 交互记录 |
| 评测集 | `/root/workspace/evalset.jsonl` | 包含 answer 的评测集 |
| 配置文件 | `/root/workspace/task.yaml` | 任务配置文件 |

#### 输出文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 评测结果 | `/root/workspace/result.json` | 单个 case 的评测结果 |

#### 执行示例

```bash
astron-eval eval \
  --task-id agent-eval-abc123 \
  --case-id case-001 \
  --transcript /root/workspace/transcript.jsonl \
  --evalset /root/workspace/evalset.jsonl \
  --model ID_JUDGE_001 \
  --verbose
```

### 2.5 report 命令

#### 命令格式

```bash
astron-eval report --task-id <task_id> [options]
```

#### 专用参数

| 参数 | 短参数 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| `--results-dir` | `-r` | string | 否 | 评测结果目录（默认工作目录） |
| `--output` | `-o` | string | 否 | 报告输出目录（默认工作目录） |
| `--format` | `-f` | string | 否 | 报告格式：json/html/all（默认 all） |

#### 输入文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 评测结果 | `/root/workspace/results/*.json` | 所有 case 的评测结果 |
| 配置文件 | `/root/workspace/task.yaml` | 任务配置文件 |

#### 输出文件

| 文件 | 路径 | 说明 |
|------|------|------|
| JSON 报告 | `/root/workspace/conclusion.json` | 评测结论（JSON 格式） |
| HTML 报告 | `/root/workspace/conclusion.html` | 评测报告（HTML 格式） |

#### 执行示例

```bash
astron-eval report \
  --task-id agent-eval-abc123 \
  --results-dir /root/workspace \
  --format all \
  --verbose
```

### 2.6 合并模式命令

当 `merge_eval: true` 时，inference 和 eval 合并执行：

#### 命令格式

```bash
astron-eval inference-eval --task-id <task_id> --case-id <case_id> [options]
```

#### 执行示例

```bash
astron-eval inference-eval \
  --task-id agent-eval-abc123 \
  --case-id case-001 \
  --agent-type claude-code \
  --eval-model ID_JUDGE_001 \
  --timeout 15m \
  --verbose
```

## 三、文件格式定义

### 3.1 评测集格式（evalset.jsonl）

评测集采用 JSONL 格式，每行一个 JSON 对象：

```jsonl
{"case_id": "case-001", "question": "如何实现一个排序算法？", "instruction": "请使用 Python 实现", "reference": {"expected_output": "..."}}
{"case_id": "case-002", "question": "分析这段代码的时间复杂度", "instruction": "代码见附件", "reference": {"expected_output": "O(n log n)"}}
```

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `case_id` | string | 是 | Case 唯一标识 |
| `question` | string | 是 | 问题内容 |
| `instruction` | string | 否 | 操作说明/补充指令 |
| `context` | object | 否 | 上下文信息（如附件、代码片段） |
| `reference` | object | 否 | 参考答案/预期结果 |
| `answer` | string | 否 | Agent 回答（inference 阶段填充） |
| `eval_config` | object | 否 | 评测配置（评测维度、标准等） |

#### inference 后的评测集

inference 阶段执行后，评测集会添加 `answer` 字段：

```jsonl
{"case_id": "case-001", "question": "如何实现一个排序算法？", "answer": "以下是 Python 实现的快速排序算法...", "reference": {...}}
```

### 3.2 交互记录格式（transcript.jsonl）

记录 Agent 执行过程中的所有交互：

```jsonl
{"timestamp": 1761983600, "role": "user", "content": "如何实现一个排序算法？"}
{"timestamp": 1761983601, "role": "assistant", "content": "我来帮你实现...", "tool_calls": [...]}
{"timestamp": 1761983602, "role": "tool", "name": "write_file", "content": "文件已创建"}
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `timestamp` | int64 | 时间戳（秒） |
| `role` | string | 角色：user/assistant/tool/system |
| `content` | string | 消息内容 |
| `tool_calls` | array | 工具调用（assistant 角色） |
| `name` | string | 工具名称（tool 角色） |
| `metadata` | object | 元数据（token 统计等） |

### 3.3 评测结果格式（result.json）

单个 case 的评测结果：

```json
{
  "case_id": "case-001",
  "task_id": "agent-eval-abc123",
  "evaluated_at": 1761983700,
  "dimensions": [
    {
      "name": "correctness",
      "score": 90.0,
      "max_score": 100,
      "reason": "代码逻辑正确，边界情况处理完善",
      "details": {
        "test_cases_passed": 9,
        "test_cases_total": 10
      }
    },
    {
      "name": "code_quality",
      "score": 85.0,
      "max_score": 100,
      "reason": "代码结构清晰，命名规范"
    }
  ],
  "overall_score": 87.5,
  "usage": {
    "input_tokens": 1500,
    "output_tokens": 800
  }
}
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `case_id` | string | Case 唯一标识 |
| `task_id` | string | 任务 ID |
| `evaluated_at` | int64 | 评测时间戳 |
| `dimensions` | array | 各维度评测结果 |
| `dimensions[].name` | string | 维度名称 |
| `dimensions[].score` | float | 得分 |
| `dimensions[].max_score` | float | 最高分 |
| `dimensions[].reason` | string | 评分理由 |
| `overall_score` | float | 综合得分 |
| `usage` | object | Token 消耗统计 |

## 六、错误处理规范

### 6.1 退出码定义

| 退出码 | 含义 | 说明 |
|--------|------|------|
| 0 | 成功 | 命令执行成功 |
| 1 | 通用错误 | 未指定的错误 |
| 2 | 参数错误 | 命令行参数无效 |
| 3 | 配置错误 | 配置文件无效或缺失 |
| 4 | 输入错误 | 输入文件无效或缺失 |
| 5 | 执行错误 | 执行过程中出错 |
| 6 | 超时错误 | 执行超时 |
| 7 | 资源错误 | 资源不足或不可用 |

### 6.2 错误输出格式

错误信息输出到 stderr，格式如下：

```
[ERROR] <error_code>: <error_message>
Details: <detailed_information>
```

**示例**：

```
[ERROR] EVAL_001: Failed to load evalset file
Details: File not found: /root/workspace/evalset.jsonl
```

### 6.3 日志输出格式

日志输出到 stdout，采用结构化格式：

```
[<timestamp>] <level> [<module>] <message>
```

**示例**：

```
[2026-04-09 10:00:00] INFO [synthesis] Starting synthesis for task agent-eval-abc123
[2026-04-09 10:00:05] INFO [synthesis] Generated 10 cases
[2026-04-09 10:00:05] INFO [synthesis] Synthesis completed successfully
```

### 6.4 重试建议

| 错误类型 | 是否可重试 | 建议操作 |
|----------|-----------|----------|
| 网络超时 | 是 | 延迟重试 |
| API 限流 | 是 | 指数退避重试 |
| 资源不足 | 是 | 等待资源释放后重试 |
| 配置错误 | 否 | 修正配置后重新执行 |
| 输入错误 | 否 | 修正输入后重新执行 |

## 七、与执行服务集成

### 7.1 执行服务调用流程

```go
// 1. 准备阶段：上传资源
resourceHandler.PrepareResources(ctx, sandbox, subTask)
// 上传 skills 目录
// 上传 task.yaml 配置文件
// 下载 evalset.jsonl（如需要）

// 2. 执行阶段：构建并执行命令
cmd := buildCommand(subTask)
output, err := sandbox.ExecuteCommand(ctx, cmd, timeout)

// 3. 收集阶段：下载结果文件
outputs := resultCollector.CollectResults(ctx, sandbox, subTask)
```

### 7.2 命令构建逻辑

```go
func buildCommand(subTask *SubTaskContext) string {
    workDir := "/root/workspace"
    
    switch subTask.Stage {
    case "synthesis":
        return fmt.Sprintf(
            "cd %s && astron-eval synthesis --task-id %s --count %d --verbose",
            workDir, subTask.TaskId, subTask.Config.Synthesis.Count,
        )
        
    case "inference":
        return fmt.Sprintf(
            "cd %s && astron-eval inference --task-id %s --case-id %s --timeout %s --verbose",
            workDir, subTask.TaskId, subTask.CaseId, subTask.Config.Inference.Timeout,
        )
        
    case "eval":
        return fmt.Sprintf(
            "cd %s && astron-eval eval --task-id %s --case-id %s --verbose",
            workDir, subTask.TaskId, subTask.CaseId,
        )
        
    case "report":
        return fmt.Sprintf(
            "cd %s && astron-eval report --task-id %s --format all --verbose",
            workDir, subTask.TaskId,
        )
        
    default:
        return ""
    }
}
```

### 7.3 结果收集逻辑

```go
func collectResults(sandbox *Sandbox, stage string) (map[string][]byte, error) {
    results := make(map[string][]byte)
    
    var filesToCollect []string
    switch stage {
    case "synthesis":
        filesToCollect = []string{"evalset.jsonl", "dataset.jsonl"}
    case "inference":
        filesToCollect = []string{"transcript.jsonl", "evalset.jsonl"}
    case "eval":
        filesToCollect = []string{"result.json"}
    case "report":
        filesToCollect = []string{"conclusion.json", "conclusion.html"}
    }
    
    for _, filename := range filesToCollect {
        path := "/root/workspace/" + filename
        content, err := sandbox.ReadFile(path)
        if err == nil {
            results[filename] = content
        }
    }
    
    return results, nil
}
```

### 7.4 超时处理

```go
func executeWithTimeout(sandbox *Sandbox, cmd string, timeout time.Duration) (string, error) {
    ctx, cancel := context.WithTimeout(context.Background(), timeout)
    defer cancel()
    
    output, err := sandbox.ExecuteCommand(ctx, cmd)
    if ctx.Err() == context.DeadlineExceeded {
        return "", errors.ErrSandboxExecuteTimeout
    }
    return output, err
}
```

## 八、版本兼容性

### 8.1 版本号规则

采用语义化版本（Semantic Versioning）：`MAJOR.MINOR.PATCH`

- **MAJOR**：不兼容的 API 变更
- **MINOR**：向后兼容的功能新增
- **PATCH**：向后兼容的问题修复

### 8.2 版本检查

```bash
astron-eval --version
# 输出: astron-eval version 1.0.0
```

### 8.3 兼容性矩阵

| astron-eval | Claude Code | Open Claw | 执行服务 |
|-------------|-------------|-----------|----------|
| 1.0.x | ≥ 1.0.0 | ≥ 1.0.0 | ≥ 1.0.0 |

## 十、附录

### A. 完整命令参考

```bash
# synthesis 命令
astron-eval synthesis --task-id <task_id> [--count <n>] [--model <model_id>] [--verbose]

# inference 命令
astron-eval inference --task-id <task_id> --case-id <case_id> [--timeout <duration>] [--agent-type <type>] [--verbose]

# eval 命令
astron-eval eval --task-id <task_id> --case-id <case_id> [--model <model_id>] [--verbose]

# report 命令
astron-eval report --task-id <task_id> [--format <json|html|all>] [--verbose]

# inference-eval 合并命令
astron-eval inference-eval --task-id <task_id> --case-id <case_id> [--timeout <duration>] [--verbose]

# 版本查看
astron-eval --version

# 帮助信息
astron-eval --help
astron-eval synthesis --help
astron-eval inference --help
```

### B. 环境变量完整列表

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ASTRON_EVAL_WORK_DIR` | `/root/workspace` | 工作目录 |
| `ASTRON_EVAL_CONFIG` | `/root/.astron-eval/config.yaml` | 配置文件路径 |
| `ASTRON_EVAL_LOG_LEVEL` | `INFO` | 日志级别 |
| `ASTRON_EVAL_LOG_DIR` | `/root/workspace/.astron-eval/logs` | 日志目录 |
| `OPENAI_API_KEY` | - | OpenAI API 密钥 |
| `OPENAI_API_URL` | - | OpenAI API 地址 |
| `ANTHROPIC_API_KEY` | - | Anthropic API 密钥 |
| `CLAUDE_CODE_SKILLS_DIR` | `/root/.claude/skills` | Claude Code Skills 目录 |

### C. 示例配置文件

```yaml
# /root/.astron-eval/config.yaml
version: 1.0

logging:
  level: INFO
  format: json
  output: /root/workspace/.astron-eval/logs

models:
  - id: ID_JUDGE_001
    type: api-openai
    api_url: ${OPENAI_API_URL}
    api_key: ${OPENAI_API_KEY}
    model: deepseek-r1
    
claude_code:
  skills_dir: /root/.claude/skills
  timeout: 10m
  
eval:
  default_dimensions:
    - name: correctness
      weight: 0.5
    - name: completeness
      weight: 0.3
    - name: clarity
      weight: 0.2
```
