> 来源：`/home/xmq/projects/go/agent-eval-design`

## 一、概述

### 1.1 任务定义说明

应用评测任务通过YAML配置文件定义，包含：
- 评测流程定义（workflow阶段序列）
- 评测模型配置（评委模型、被评测模型）
- 各阶段执行配置

### 1.2 Workflow阶段概览

应用评测包含四个可选阶段，按顺序执行：

| 阶段 | 说明 | 输入 | 输出 |
|-----|------|------|------|
| synthesis | 评测集合成 | 场景描述、skills | dataset.jsonl, evalset.jsonl |
| inference | Agent推理执行 | evalset.jsonl, skills | transcript.jsonl, evalset.jsonl(含answer) |
| eval | 评测执行 | evalset.jsonl | result.json |
| report | 报告生成 | result.json | conclusion.json, conclusion.html |

**执行模式**：
- 完整流程：synthesis → inference → eval → report
- 部分流程：可配置只执行部分阶段（如只执行 eval → report）

## 二、任务配置定义

### 2.1 配置结构总览

```
任务配置 (task.yaml)
├── version          # 配置版本
├── description      # 任务描述
├── workflow         # 执行阶段列表
├── models           # 模型配置列表
└── <stage>          # 各阶段配置
    ├── synthesis
    ├── inference
    ├── eval
    └── report
```

### 2.2 根级字段

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| version | string | 是 | 配置版本，格式：1.0.0 |
| description | string | 否 | 任务描述，用于报告生成 |
| workflow | array | 是 | 执行阶段列表，如：[synthesis, inference, eval, report] |
| models | array | 否 | 模型配置列表，详见2.3节 |

**配置示例**：

```yaml
version: 1.0.0
description: 场景描述

workflow: 
 - synthesis
 - inference
 - eval
 - report

models:
  - id: ID_JUDGE_001
    type: api-openai
    api_key: xxx
    api_url: https://...
    concurrency: 40
    model: xdeepseekr1
```

### 2.3 模型配置

models 数组定义评测所需的大模型配置：

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| id | string | 是 | 模型标识，用于其他配置引用 |
| type | enum | 是 | 模型类型：api-openai / api-anthropic |
| api_key | string | 是 | API访问密钥 |
| api_url | string | 是 | API访问地址 |
| model | string | 是 | 模型调用名称 |
| concurrency | int | 是 | 并发路数 |

**配置示例**：

```yaml
models:
  - id: ID_JUDGE_001
    type: api-openai
    api_key: 527bdfdb89f9191848ef21902f912e82:ODBlYjI2ZTVkMTdjYmVjMDc2N2M5ZGMx
    api_url: https://maas-api.cn-huabei-1.xf-yun.com/v2
    concurrency: 40
    model: xdeepseekr1
```

## 三、Workflow阶段定义

### 3.1 synthesis 阶段

**功能**：根据场景描述或skill生成评测集

**配置字段**：

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| type | enum | 是 | 合成类型：agent |
| count | int | 是 | 生成的评测条数 |
| model | string | 是 | 使用的模型ID（引用models配置） |

**配置示例**：

```yaml
synthesis:
  type: agent
  count: 10
  model: ID_JUDGE_001
```

**输入**：
- 场景描述（description字段）
- skills 目录

**输出**：
- `dataset.jsonl` - 评测集输入
- `evalset.jsonl` - 评测集输出
- `llm-record.jsonl` - LLM调用记录

### 3.2 inference 阶段

**功能**：执行Agent推理，获取模型回答

**配置字段**：

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| type | enum | 是 | 推理类型：claude-code / astron-claw / open-claw |
| model | string | 是 | 使用的模型ID |

**配置示例**：

```yaml
inference:
  type: claude-code
  model: ID_JUDGE_001
```

**输入**：
- `evalset.jsonl` - 评测集（含question）
- skills 目录

**输出**：
- `transcript.jsonl` - 交互记录
- `evalset.jsonl` - 评测集（更新answer字段）

### 3.3 eval 阶段

**功能**：执行评测，计算评测指标

**配置字段**：

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| model | string | 是 | 评委模型ID |

**配置示例**：

```yaml
eval:
  model: ID_JUDGE_001
```

**输入**：
- `evalset.jsonl` - 评测集（含question和answer）

**输出**：
- `result.json` - 评测结果

### 3.4 report 阶段

**功能**：生成评测报告

**配置字段**：

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| type | enum | 是 | 报告类型：agent / model |
| model | string | 是 | 使用的模型ID |

**配置示例**：

```yaml
report:
  type: agent
  model: ID_JUDGE_001
```

**输入**：
- `result.json` - 评测结果

**输出**：
- `conclusion.json` - 评测结论
- `conclusion.html` - 可视化报告

## 四、工作区目录结构

### 4.1 整体结构

```
workspace/
├── resource/              # 资源文件（pdf, txt, xlsx, docx等）
├── skills/                # Agent技能配置
│   ├── driven/
│   │   └── SKILL.md
│   └── sed/
│       └── SKILL.md
├── .env                   # 环境变量配置
├── synthesis/             # synthesis阶段产物
├── task/                  # 任务执行目录
│   ├── case1/
│   │   ├── inference/
│   │   └── eval/
│   ├── case2/
│   └── case3/
└── report/                # 报告产物
```

### 4.2 各阶段目录

**synthesis 阶段**：

```
synthesis/
├── dataset.jsonl      # 评测集输入
├── evalset.jsonl      # 评测集输出
└── llm-record.jsonl   # LLM调用记录
```

**inference 阶段** (单个case)：

```
task/<case_id>/inference/
├── testcase.json      # 输入，含评测点
├── transcript.jsonl   # 交互记录
├── evalset.jsonl      # 评测集输出（含answer）
├── a.txt              # 其他输出文件
├── b.pdf
└── c.xlsx
```

**eval 阶段** (单个case)：

```
task/<case_id>/eval/
├── evalset.jsonl      # 输入：含评测点
├── result.json        # 输出：评测结果
└── transcript.jsonl   # 交互记录
```

**report 阶段**：

```
report/
├── eval.jsonl         # 输入：评测结果
├── conclusion.json    # 评测结论
└── conclusion.html    # 可视化报告
```

## 七、命令执行方式

评测工具通过命令行执行：

```bash
# 执行完整流程
astron-eval --config all-task.yaml --setting all-setting.yaml

# 执行synthesis阶段
astron-eval --config synthesis-task.yaml --setting synthesis-setting.yaml

# 执行inference+eval阶段
astron-eval --config inference+eval-task.yaml --setting inference+eval-setting.yaml

# 执行report阶段
astron-eval --config report-task.yaml --setting report-setting.yaml
```
