# 子任务处理器设计

## 一、概述

定义子任务处理的统一接口，不同任务类型和阶段实现具体的资源准备、命令执行、结果收集逻辑。

**职责边界**：
- 每个 Handler 负责 (type, sub_type) 组合的完整执行流程
- 不关注沙箱生命周期管理（由 SandboxManager 处理）

---

## 二、结构与数据模型

### 2.1 SubTaskHandler 接口

```go
type SubTaskHandler interface {
    Prepare(ctx, sandbox, subTask) error            // 准备资源（上传文件、下载评测集）
    Execute(ctx, sandbox, subTask) (*ExecutionResult, error)  // 执行命令
    Collect(ctx, sandbox, subTask) (*SubTaskResult, error)    // 收集结果
    GetTimeout() time.Duration                       // 获取超时时间
}
```

### 2.2 SubTaskHandlerRegistry

```go
type SubTaskHandlerRegistry struct {
    handlers map[string]map[string]SubTaskHandler  // type → sub_type → Handler
    logger   *zap.Logger
}
```

| 方法 | 说明 |
|------|------|
| Register(type, subType, handler) | 注册处理器 |
| GetHandler(type, subType) (SubTaskHandler, error) | 获取处理器 |

## 三、核心逻辑

### 3.1 执行流程示例（AgentEvalInferenceHandler）

```go
type AgentEvalInferenceHandler struct {
    agentCubeClient *AgentCubeClient
    timeout         time.Duration  // 默认 3600s
}

func (h *AgentEvalInferenceHandler) Prepare(ctx, sandbox, subTask) error {
    // 上传 skills 目录
    h.agentCubeClient.UploadDir(ctx, sandbox, "skills/", "/workspace/skills/")
    // 上传配置
    h.agentCubeClient.WriteFile(ctx, sandbox, config, "/workspace/setting.yaml")
    // 下载评测集
    h.agentCubeClient.DownloadFile(ctx, sandbox, "evalset.jsonl", "/workspace/evalset.jsonl")
    return nil
}

func (h *AgentEvalInferenceHandler) Execute(ctx, sandbox, subTask) (*ExecutionResult, error) {
    cmd := fmt.Sprintf("astron-eval inference --task-id %s --case-id %s",
        subTask.TaskId, subTask.Extra["case_id"])
    return h.agentCubeClient.ExecuteCommand(ctx, sandbox, cmd)
}

func (h *AgentEvalInferenceHandler) Collect(ctx, sandbox, subTask) (*SubTaskResult, error) {
    transcript := h.agentCubeClient.ReadFile(ctx, sandbox, "/workspace/transcript.jsonl")
    evalset := h.agentCubeClient.ReadFile(ctx, sandbox, "/workspace/evalset.jsonl")
    return parseResult(transcript, evalset)
}

func (h *AgentEvalInferenceHandler) GetTimeout() time.Duration {
    return h.timeout
}
```

## 四、扩展与集成

### 4.1 内置处理器

| (type, sub_type) | Handler | 命令模板 |
|------------------|---------|----------|
| (agent_eval, synthesis) | AgentEvalSynthesisHandler | `astron-eval synthesis --task-id {TaskId}` |
| (agent_eval, inference) | AgentEvalInferenceHandler | `astron-eval inference --task-id {TaskId} --case-id {CaseId}` |
| (agent_eval, eval) | AgentEvalEvalHandler | `astron-eval eval --task-id {TaskId} --case-id {CaseId}` |
| (agent_eval, report) | AgentEvalReportHandler | `astron-eval report --task-id {TaskId}` |
| (model_eval, inference) | ModelEvalInferenceHandler | `astron-model inference --task-id {TaskId} --case-id {CaseId}` |
| (model_eval, eval) | ModelEvalEvalHandler | `astron-model eval --task-id {TaskId} --case-id {CaseId}` |
| (model_eval, report) | ModelEvalReportHandler | `astron-model report --task-id {TaskId}` |

### 4.2 结果文件收集规则

| (type, sub_type) | 收集文件 |
|------------------|----------|
| (agent_eval, synthesis) | dataset.jsonl, evalset.jsonl |
| (agent_eval, inference) | transcript.jsonl, evalset.jsonl |
| (agent_eval, eval) | result.json |
| (agent_eval, report) | conclusion.json, conclusion.html |
| (model_eval, inference) | response.jsonl |
| (model_eval, eval) | result.json |
| (model_eval, report) | report.xlsx |

### 4.3 扩展方式

```go
// 1. 定义 Handler
type SafetyEvalInferenceHandler struct{}

func (h *SafetyEvalInferenceHandler) Prepare(...) error { ... }
func (h *SafetyEvalInferenceHandler) Execute(...) (*ExecutionResult, error) { ... }
func (h *SafetyEvalInferenceHandler) Collect(...) (*SubTaskResult, error) { ... }
func (h *SafetyEvalInferenceHandler) GetTimeout() time.Duration { return 1800 }

// 2. 注册
registry.Register("safety_eval", "inference", &SafetyEvalInferenceHandler{})
```
